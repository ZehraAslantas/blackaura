# ☕ Black Aura Coffee — Frontend

**Black Aura Coffee**, modern kahve ve tatlı konseptini karanlık tema (Dark Mode) tasarımıyla sunan responsive bir web menü arayüzüdür.

> Bu depo projenin ön yüz (frontend) kodlarını barındırmaktadır. İlerleyen süreçte dinamik backend yapısı bağlanacaktır.

---

### 🌟 Özellikler

* **Karanlık Tema (Dark Mode):** Markaya özel şık ve modern arayüz tasarımı.
* **Kategori Bazlı Menü:** Espresso, Filtre, Soğuk Kahveler, Tatlı & Çikolata ve Paket Kahve sayfaları.
* **Dinamik Fiyatlandırma:** Seçilen porsiyon/boyuta göre fiyatı anlık güncelleyen hafif JavaScript yapısı.
* **Mobil Uyumlu (Responsive):** Tüm cihazlara uyumlu Bootstrap grid düzeni ve Offcanvas bilgi paneli.

---

### 🛠️ Teknolojiler

* **HTML5 & CSS3:** Sayfa yapısı ve özel stiller (`style.css`).
* **Bootstrap 5.3.8:** Grid mimarisi, kart bileşenleri ve offcanvas menü.
* **Vanilla JavaScript:** Boyut değişiminde `data-price` değerini okuyup güncelleyen saf DOM scripti (`updatePrice`).
